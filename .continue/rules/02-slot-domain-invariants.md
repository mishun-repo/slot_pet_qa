# Slot Machine Domain QA Invariants

При тестировании `slot_pet_project` всегда проверяй следующие инварианты:
1. **Баланс (Financial Integrity)**:
   - `balance_after == balance_before - bet + win`.
   - Баланс никогда не может уйти в минус; ставка `> balance` должна блокироваться и на UI, и на уровне API.
   - Запрещены отрицательные, нулевые (если не предусмотрен demo/free spin) или невалидные строковые ставки.
2. **Атомарность и Идемпотентность спина**:
   - Двойной клик по кнопке Spin (или спам `Space`) во время вращения не должен списывать двойную ставку.
3. **Граничные значения (BVA)**:
   - Min bet, Max bet, баланс == ставке, баланс == 0, крупный выигрыш (Big Win / Jackpot), автоспин.
4. **RNG и Детерминизм в автотестах**:
   - Если в `slot_pet_project` нельзя замокать RNG на бэкенде, перехватывай ответ API спина (`page.route`) в UI-тестах для проверки визуального отображения выигрышных линий/символов, а интеграцию с реальным API проверяй на математику баланса.
